# A quiet handoff for the shared workbench

Before leaving a shared bench, write three things on its paper card: which tool is still out, what material is drying, and the next safe starting point. A short factual handoff is more useful than a promise that everything is finished.

For this notebook entry, the soldering iron is unplugged, the blue storage tray holds the unfinished cardboard jig, and the next session begins by checking the jig against a fresh scrap. The note records a stopping point; it does not authorize anyone to energize equipment.
